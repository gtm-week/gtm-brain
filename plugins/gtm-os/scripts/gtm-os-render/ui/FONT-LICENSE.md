# Bundled typefaces

The dashboard ships its own faces so it renders the same offline, inside Codex and in a browser.
All three are SIL Open Font License 1.1, which permits bundling and redistribution.

| Family | Files | Source | License |
| --- | --- | --- | --- |
| Inter | `fonts/inter-latin.woff2`, `fonts/inter-latin-ext.woff2` | github.com/rsms/inter | SIL OFL 1.1 |
| Space Grotesk | `fonts/space-grotesk-latin.woff2`, `fonts/space-grotesk-latin-ext.woff2` | github.com/floriankarsten/space-grotesk | SIL OFL 1.1 |
| JetBrains Mono | `fonts/jetbrains-mono-latin.woff2`, `fonts/jetbrains-mono-latin-ext.woff2` | github.com/JetBrains/JetBrainsMono | SIL OFL 1.1 |

Each file is the variable weight axis for that family, in the latin and latin-ext subsets. The
latin-ext subset carries the Polish diacritics the dashboard needs in its second language.

The OFL requires that the license travels with the fonts and that they are not sold on their own.
