# GTM OS: Save

Keep authored brain content in English. Preserve names, source quotes and the exact approval token `APPROVE`.


> For humans: notes, summaries and names Codex writes are kept at once. This is for the rare case
> where you edited a file yourself and want it kept too.

Call the GTM OS tool `save` with `brain` = this workspace folder and `message` = one line saying
what changed. No shell command. Only when the person asks; never on your own.

Report in the person's language, without git words: *"Kept: your edit to the pipeline
summary."* If it says nothing to save, say so in one line. If it refused because a change to the
workplace info is waiting for APPROVE, ask for APPROVE or a drop first.

Saving records a manual edit but does not approve overwriting it. If compilation is paused,
review the changes with the person using the compile procedure. Never clear a pause merely
because the file was saved or committed.

## Hard rules

- Never call `save` without the person asking. Codex's own writes never need it.
- Never rewrite history, never force push, never commit `work/`.
