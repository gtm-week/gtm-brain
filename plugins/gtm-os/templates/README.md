# {{COMPANY}} brain

Made with GTM OS. Three kinds of things live in this folder.

- **A document**: something we wrote and the work must follow. `strategy.md`, `brand/voice.md`,
  `pricing/pricing.md`. One Markdown file is the document; its files, if any, live in a folder of
  the same name beside it (`strategy/deck.pdf`). Any folder name works. Wrote one by hand? Say
  `add strategy.md as a document`.
- **A project**: a folder for one piece of work (`website/`, an event). Make or link one with
  `/gtm-os-project`; open it in Codex and work there.
- **`brain/`**: what Codex remembers: notes by topic, people, companies. Read it; let Codex write
  it. `work/` is scratch and stays out of git.

Nothing else belongs at this level. Did it happen? Say it in the chat; Codex notes it.
