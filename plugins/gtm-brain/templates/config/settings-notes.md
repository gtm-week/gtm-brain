## How we work

- Contexts hold shared knowledge about topics. Use the relevant context for the requested work.
- Tools are read live when a context names them. The brain never holds a copy.
- Memories name their authors by handle; the handles are in `team` above.
- This file is the workplace info. Only the owner (`owner` above) changes it, or anything else in
  config/ and about-us/: Codex explains the change, the owner's APPROVE in its form applies and
  commits it. A teammate's change waits as a proposal for the owner.
- The dashboard opens in the Codex pane and needs no login. `dashboard: always | on-demand`
  controls its timing guidance. A topic summary is written when someone asks about it.
- A file over 25 MB never goes into git. `big_files: google-drive` moves it to the shared drive
  and links it; `big_files: local` keeps it in a folder on this computer outside git (not
  shared, linked as a `file:` path; `big_files_folder:` names the folder).
