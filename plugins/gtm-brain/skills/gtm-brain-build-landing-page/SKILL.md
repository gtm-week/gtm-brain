# GTM Brain: Build a landing page

1. Resolve and reuse the shared website through
   [the project flow](../gtm-brain-design-system/references/project.md). A new campaign adds
   a page there, not a new starter or copied component library.
2. Read applicable strategy, ICP, offer, voice and design documents and relevant context.
   Form the brief around audience, campaign context, offer, action, route and approved copy.
   Reuse an existing brief exactly; ask only for missing decisions. Clearly mark missing
   claims, quotes and content. Do not use the lesson's Ramp offer as company evidence.
3. Read `docs/workflows/build-landing-page/SKILL.md` from that project in full and follow
   Brian's section mapping, brief review, composition, SEO and verification procedure.
   Route a missing section through [Add section](../gtm-brain-add-section/SKILL.md) before
   consuming it. Keep the original method rather than writing a parallel page-building recipe.
4. Return the local page URL, checks at 375, 768 and 1440, and unresolved placeholders or
   forms. Inspect existing pages affected by shared changes. This workflow stops locally,
   including when the original procedure offers a pushed preview for a live site.
   [Publish website](../gtm-brain-publish-website/SKILL.md) requires a separate request.
