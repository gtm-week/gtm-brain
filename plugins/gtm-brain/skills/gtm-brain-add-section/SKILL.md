# GTM Brain: Add a reusable section

1. Resolve the company's shared website through
   [the project flow](../gtm-brain-design-system/references/project.md). Reuse its components
   and approved design. If the system has not been set up, complete that prerequisite first.
2. Reuse the supplied source URL and section heading, or the brief for a new section.
   Ask only for missing content, behaviour and business decisions. A calculator's formulas
   belong in its brief; there is no fixed calculator product or additional skill.
3. In that project, read `docs/workflows/add-section/SKILL.md` in full and follow it.
   Retain Brian's component composition, typed registry, documentation and verification
   method. Register the section for reuse by all campaigns, not just the current page.
4. Return its local catalogue preview, relevant interaction checks and results at all
   three widths. Report missing copy or unconnected services. Review any shared component
   changes against existing pages. Leave remote publication for a separate request.
