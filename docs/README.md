# GTM Brain documentation

Read in this order. The short introduction is the [README](../README.md); installing starts at [INSTALL.md](../INSTALL.md) in the top folder; how a
brain works inside is in [the manual](../plugins/gtm-brain/MANUAL.md), which ships with the plugin.

- [HOW-IT-WORKS.md](HOW-IT-WORKS.md): the four parts of a brain, how they fit together, what is stored on disk, sources and boundaries.
- [SKILLS.md](SKILLS.md): the twenty-nine shipped skills, in order: rules and schema, mentors, everyday, setup and maintenance.
- [ONBOARDING.md](ONBOARDING.md): the first-use walkthrough, from nothing installed to a working brain.
- [GUIDE.md](GUIDE.md): everyday use: what to say in a chat, examples by situation, the dashboard, your tools and sync, the workshop demo.
- [COMMANDS.md](COMMANDS.md): every skill, tool and command, and the files each one writes.
- [DOCUMENTS.md](DOCUMENTS.md): the documents the work must follow (strategy, voice, pricing) and how they are made.
- [WORKFLOWS.md](WORKFLOWS.md): skills in sequence, with triggers, gates and milestones.
- [USER-SKILLS.md](USER-SKILLS.md): making a skill of your own, where it shows up and how it travels.
- [SETUP.md](SETUP.md): manual installation, Claude Code (beta), and the contributor's verification steps.
- [MIGRATING.md](MIGRATING.md): moving an installation from the earlier `gtm-os` name to GTM Brain.
- [releases/](releases/): what each release changes and its known limits. Latest: [0.35](releases/RELEASE-0.35.md).

Not part of the reading order:

- [WALKTHROUGH.md](WALKTHROUGH.md): the step-by-step setup with troubleshooting, kept as the source text of the Circle onboarding guide.
- [DESIGN.md](DESIGN.md): the brand and design rules for the GTM Brain name, logo and pages.
- [skill-template/](skill-template/README.md): for contributors, the folder to copy for a skill that ships with the plugin.
- [releases/template/](releases/template/README.md): the release graphic, its style rules and the script that renders it.
- [images/](images/): the picture and the dashboard screenshots the README and the guides show.
