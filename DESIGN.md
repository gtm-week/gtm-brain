# GTM Brain brand and design

The live reference is [gtm-brain.ai](https://gtm-brain.ai/). Use the existing approved GTM Brain
artwork and the [GTM Week design contract](https://www.gtm-week.com/DESIGN.md).

## Identity

- Product: **GTM Brain**.
- Website: https://gtm-brain.ai/.
- Source and installation: https://github.com/gtm-week/gtm-brain.
- Logo: [approved GTM Brain holographic square](plugins/gtm-brain/assets/logo.png), reused unchanged from the website.
- Audience: GTM engineers. Lead with the work, the problem it solves and the evidence behind the result.

## Visual direction

Warm paper (`#F6F1E8`), paper panels (`#FFFAF0`), black ink (`#070707`) and a deliberate lime
signal (`#B8FF00`). Space Grotesk for display, Inter for body and controls, JetBrains Mono for
labels and system language. Keep square borders, visible rules, aligned grids and hard shadows.
The approved holographic artwork is a contained brand asset. Preserve its composition.

Explain workflows through inputs, steps, evidence and outputs. Use specific prompts and honest
examples. Respect the existing product interface and its accessibility when applying these rules.

## Links and assets

The README and plugin link to the website. Website source links and command examples use
`gtm-week/gtm-brain` and `/gtm-brain-*`. Keep those links aligned when publishing.

The logo was approved for GTM Brain on the website before this rename. Its provenance is the
existing GTM Week holographic artwork with the approved Brain name variant; this release reuses
the delivered asset and does not regenerate it.
